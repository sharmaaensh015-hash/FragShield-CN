The idea

A packet mixes critical and optional data, and one corrupted field keeps hurting later states (filters, integrators, latched failsafes). FragShield spends a fixed redundancy budget where corruption would spread furthest.

What this test proves

The browser sends a request to a local Python bridge, which emits one real UDP datagram. The receiver decodes byte-wise extended Hamming SECDED and checks a CRC32 checksum. UDP itself does not guarantee delivery, so check Computer B's receiver terminal for the received packet and decode result.

Where it wins, where it doesn’t

  • Wins: tight budgets (about 5–20%): clearly less downstream damage than classic UEP at equal overhead.
  • Ties or loses: at larger budgets classic UEP catches up; bit-exact battery/altitude recovery is lower because their low bits are left bare on purpose. Drag the budget slider and watch.
  • Caveats: it is a simulation of a drone-telemetry link. This page re-implements the Python simulator in JavaScript with shorter missions, so numbers differ slightly from the repository’s 20-seed results; the damage model scores and evaluates (on different missions).
