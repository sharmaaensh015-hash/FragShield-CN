# FragShield — Computer Networks Project

## Overview
FragShield is a Computer Networks project focused on error detection and network communication. It demonstrates concepts used to understand data integrity and UDP-based communication.

## Features
- Web-based interface for exploring the project.
- Error-detection demonstration.
- Python-based UDP receiver and local web bridge.
- Browser-based project interface hosted using GitHub Pages.

## Technologies Used
- HTML, CSS and JavaScript
- Python
- UDP networking
- GitHub Pages

## Project Files
- `index.html` — Main website interface.
- `fragshield_network.py` — Python program for the UDP receiver and local web bridge.

## Running the UDP Component
The Python networking component must be run separately on a computer with Python installed. GitHub Pages hosts the static website; it does not run the Python backend.

Refer to the project's setup instructions for the correct commands and network configuration.
